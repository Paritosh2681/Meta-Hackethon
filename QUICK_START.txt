KEY DESIGN DECISIONS
═══════════════════════════════════════════════════════════════════════════════

1. No Gym/Gymnasium inheritance
   → Keeps code simple and self-contained
   → Makes the API crystal clear
   → Easier to understand and modify

2. Fixed grid layout
   → Tests path-planning consistently
   → Isolates package randomness from environment randomness
   → Agents can learn spatial patterns

3. State discretization for Q-Learning
   → Manageable state space (~5000 states vs infinite continuous)
   → Tabular Q-Learning remains tractable
   → Works well with limited training episodes

4. Battery as hard termination
   → Creates risk-aware planning behavior
   → Prevents trivial circular exploration
   → Makes charging station discovery valuable

5. Pure Python (no external ML libs)
   → Environment works standalone
   → Easy to integrate with any RL framework
   → No version lock-in or dependency conflicts


EXTENDING THE ENVIRONMENT
═══════════════════════════════════════════════════════════════════════════════

  → Edit env.py line: num_packages = random.randint(3, 6)

Change grid size:
  → Edit grid.py: self.width = 20, self.height = 20

Add custom rewards:
  → Edit reward.py: Add new constants and methods

Add new actions:
  → 1. Add to VALID_ACTIONS in env.py
  → 2. Implement logic in step() method
  → 3. Update agents to handle new action

Change shelf layout:
  → Edit grid.py _create_shelves() method

SUPPORT & TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════════════════

Q: Agent keeps hitting walls
A: Grid.get_valid_moves() must be checked before move actions

Q: Q-Learning not improving
A: Increase episodes (1000+), adjust learning rate (0.01-0.2), check reward scaling

Q: Package not picked up
A: Robot position must exactly match package location before pick_up action

Q: Battery drains at charger
A: Charging station is at (9,9). Verify robot reached exact position before charge
